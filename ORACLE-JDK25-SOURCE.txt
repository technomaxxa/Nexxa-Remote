Oracle JDK 25 Windows x64 fallback

Official download page:
https://www.oracle.com/java/technologies/downloads/

Archive URL used by the private-runtime bootstrapper:
https://download.oracle.com/java/25/latest/jdk-25_windows-x64_bin.zip

Checksum sidecar used by the bootstrapper:
https://download.oracle.com/java/25/latest/jdk-25_windows-x64_bin.zip.sha256

The installer retrieves the matching checksum over HTTPS and verifies the downloaded archive before extraction. Oracle's runtime is not included in this repository. Review the license terms displayed by Oracle for the exact JDK release before redistribution.
