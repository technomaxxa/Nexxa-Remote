# Security Policy

## Project status

Nexxa Remote is beta remote-access software and has not had an independent security audit. Do not expose it directly to the public Internet or use it for sensitive unattended access without an independent review.

## Reporting a vulnerability

Please do not disclose exploitable details in a public issue. Use GitHub's private vulnerability reporting for `technomaxxa/Nexxa-Remote` if enabled. If private reporting is unavailable, contact the maintainer through the GitHub profile with a concise report.

Do not include real invitation links, session access keys, certificate stores, DPAPI files, private IPs, or personal data in a report unless the maintainer explicitly asks for a secure transfer method.

## Supported baseline

Security reports should identify the Nexxa version, Windows version, Tailscale version, and exact reproduction steps. The project currently targets Windows 10/11 x64 and requires Tailscale for networking.
